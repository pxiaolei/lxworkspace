# 内部配置基础库

仅保留 fog_config.py 和空包入口，完整保留配置 helper API 供海报/分析引用。无私人数据库、Excel、缓存、指标计算的 lazy exports。调用方负责先预览，再按动作范围确认。save_fog_config/save_personal_config 为内部配置保存能力，真实配置写入必须另外授权；首版初始化不调用这两个函数。

## 执行契约

### 输入

调用方项目路径及本机 YAML 配置；保存需另行明确授权。

### 输出

配置字典或项目相对路径；保存仅由已授权调用方触发。

### 验收

包 import 不加载私人数据库/Excel、不查库；配置读取不写文件。保存能力保持内部，不隐式执行。
