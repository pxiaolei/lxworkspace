# 业务文件约定

`00todo` 放待处理输入；处理后归到对应流程。`04数据分析/数据库查询`、`04数据分析/异动分析` 每次新建 `YYYYMMDD_HHMMSS_task`，保留输入、输出和证据。

`06后台操作/卡券生成`、`06后台操作/调账文件` 分别保存卡券 XLSX 与补款/扣款 CSV 任务。每次新建 `YYYYMMDD_HHMMSS_task/`，按需建立 `输入/`、`输出/`、`处理日志/`；先保留原件，再整理输入，生成时显式指定新输出路径，读回摘要作为证据保存。两项 Skill 只生成文件，不上传后台。未分享的业务不创建空目录，编号不必连续。

`08端内宣传图`按活动名组织任务；输入副本、通过核验的样张和正式图、临时尝试、处理日志及manifest各有独立职责，见该目录README。活动内容由伙伴提供，参考图只提供风格；未完成真实视觉核验的候选不作为成品。check/dry-run不创建活动目录。

`09端外海报图/活动TXT` 放伙伴活动内容；`产出图` 放验证通过的成品；`元数据` 放生成与二维码证据；`临时图` 放试图；`处理日志` 放执行记录。海报活动内容以用户 TXT 为准，不从库里拼活动。

业务材料留本机。源件、成品、证据不自动删除；清理临时目录先展示清单并确认。更新 Skill 不移动或重建这些目录。
