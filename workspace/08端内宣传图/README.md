# 端内宣传图目录约定

活动需求由伙伴提供，风格参考素材在lx-zuotu内。业务输入与成品只留本机；不复制私人工作区历史文件。

每次生成按活动名组织，活动名由需求文件明确填写：

```text
<活动名>/
  输入/          本次需求文件的只读留存副本
  样张/          通过物理与真实视觉核验的母版样张
  产出图/        通过全部核验的正式图
  临时图/        模型原图、压缩候选和失败尝试
  处理日志/      不含凭据的执行记录与视觉核验JSON
  manifest.json  需求/规格哈希、提交状态、尝试次数及逐张核验状态
```

check/dry-run不创建这些目录。输入不覆盖；正式成品同名且内容不同即停止。样张展示并核验通过后，用户确认批量才继续。每目标最多三次生成；已有未决任务先恢复查询，不重复付费提交。无法看图或缺核验结果时保持待核验，不能伪造通过。

原文、样张、成品、失败尝试和证据不自动清理；清理前展示清单并确认。更新Skill不改这些业务文件。Git只保留本README与.gitkeep，不提交活动内容、图片、日志、manifest或锁文件。
