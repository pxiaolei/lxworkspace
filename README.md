# lxworkspace

Windows + WorkBuddy 合作伙伴工作区。提供开城城市了解、公司库查询、基础异动、端外海报、端内宣传图、问答、卡券文件、调账文件，以及初始化、更新。数据库使用你自己的公司账号，可见数据由公司服务端控制。卡券与调账只生成本地文件，不上传后台。

开城前说“使用 lx-kaicheng，我要开福州”，即可查看开城条件、材料、流程和城市营商环境。这项能力无需账号、初始化或重新上传 Excel，只读随包资料；缺项、不同说法与时间范围会明确标出，现有调研记录不代表最新官方政策核验。

## 本机准备

安装时若缺少 Python（>=3.10）、Node.js 或 Git，初始化会直接补齐，并在结果里说明哪些是这次新装的、哪些本来就有。项目依赖在环境通过后装进工作区自己的虚拟环境，不再单独弹窗。公司库账号和密码、图片 Key、问答 token 在 `python tools/run_skill.py init-config --gui` 打开的本机窗口填写，敏感字段遮挡；保存到本机配置后重新读取核对。已有非空配置保留，取消不写入；窗口失败时联系对接人，不改用记事本。不要把这些值发到聊天、日志或 Git。公司库、图片服务、问答各自使用独立凭据。

10 个官方预设品牌的配置、Logo 和二维码已随包提供：幸福千万家、哈啰、安安用车、蔚蓝滴仕、旗妙出行极速版、易达出行、江南出行、土生途行、网路优行、日初出行。调用时仍需伙伴提供活动内容。

品牌配置在 `.workbuddy/skills/lx-haibao/brands/<brand_id>.yaml`，素材在该 Skill 的 `brand-assets/<brand_id>/`。官方文件由 `contracts/partner-brand-presets.json` 精确登记，后续新增或升级通过“更新 Skill”接收。不要手改官方预设；自定义品牌使用独立 ID，继续留本机并受保护，同名冲突时停止更新并联系我方。

## 日常说法

- “查我账号下某品牌某城市 10 月 1 日到 7 日的完单数据。”
- “分析 10 月 1 日到 7 日与 9 月 24 日到 30 日的异动。”未说周期或比较规则时先补齐，不默认日期。
- “用这份活动内容生成某品牌某城市海报。”先提供活动文字，预览后再生成。
- “用这份活动内容做司机端首页、开屏和透明弹窗图。”端内图先预览范围，确认样张并逐张看图，用户再确认批量；无法看图时保留待核验。
- “问答：司机端活动配置怎么操作？”明确提问即授权本次查询，AI 内部预览后直接调用并核对记录，不再询问确认发送；按问题需要自然解释，不套固定回答模板。
- “按这些活动信息生成免佣卡/飞涨卡文件。”收集必填项、预检后生成 XLSX，并读回验证；不创建真实卡券。
- “把这份司机补款/扣款数据生成调账文件。”预检后生成 CSV 并读回验证；不执行真实调账。
- “`/lx-update` 检查更新。”先展示版本、远端完整commit、文件变化与迁移清单，再确认升级。

命令统一通过 `python tools/run_skill.py ...`（Windows 可用 `tools\lx.cmd ...`）；WorkBuddy 按各 Skill 契约组织参数。你不需要操作 Git 命令。

Skill 统一保存在 `.workbuddy/skills`，直接由 WorkBuddy 加载。

卡券、调账分别通过 `python tools/run_skill.py kaquan ...`、`python tools/run_skill.py tiaozhang ...` 执行。卡券依赖 openpyxl，由初始化入口经确认后装入现有项目虚拟环境；调账不增加第三方依赖。任务材料放 `workspace/06后台操作/卡券生成/` 或 `调账文件/` 下的新任务目录，细则见 `workspace/README.md`。

端内宣传图通过 `python tools/run_skill.py zuotu ...` 执行，覆盖首页、开屏、透明弹窗、侧边栏和权益中心5类8规格。lx-init将端内图依赖合并到已有项目虚拟环境，不另建环境或新增Key；继续使用本工作区的KIE配置。活动输入、样张、正式图和核验证据放 `workspace/08端内宣传图/<活动名>/`，目录规则见该区域README。代码与14张必要风格图已分发并获公开授权；参考图只指导风格，不得作为当前活动事实。
